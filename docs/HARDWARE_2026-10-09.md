# Connected monitor and SSD capture

Read-only IOKit inspection on 2026-10-09 found two connected USB-C ports:

- Port 1: Dell U4919DW, active DisplayPort and USB2. DisplayPort reports 5.4 Gbps (HBR2), four lanes, tunnelling off. Its near cable identity reports a passive cable, vendor 0x17EF, product 0x30C7, USB Gen 2 capability, 5 A and a 20 V ceiling (100 W). Four PD source options are reported; the winning option is 20 V / 4.5 A / 90 W.
- Port 2: Samsung PSSD T5 EVO, active USB3. The USB device reports a 5 Gbps link. Its storage driver's ancestor USB port contains UsbIOPort pointing explicitly to Port-USB-C@2. No cable e-marker identity was reported for this connection.

The user identifies both cables as Thunderbolt 4. Neither reported active transport is a Thunderbolt link, and the current records do not establish Thunderbolt certification or the complete alternate-mode capability of either cable. The UI does not override cable ratings using the active USB link or the user's model identification.

Port 2 also retained a legacy SOPMfgString of DJI with zero vendor/product IDs. Invalid legacy identity is suppressed; the device name comes from the verified USB ancestry instead.

The sanitized `Fixtures/ports-two-cables-recorded.plist` retains physical port state, near/far identities, source options and DisplayPort properties. Serial numbers and EDID are omitted. Parser checks verify these recorded values. Live UI checks verify that only the power-source connection shows Mac input and only the SSD connection shows its read/write graphs.

Mac power input remains a system-wide measurement. Its display is scoped to the unique connected port with a reported winning power-source option. Multiple source candidates, missing port mappings and unavailable values hide the corresponding graphs. A hub's named USB storage devices share their verified upstream cable and keep separate labelled graphs.

Replugging onto different ports, multiple simultaneous chargers, hubs and other Mac models still require direct hardware testing. Cable ratings and rates remain absent when macOS does not expose them.
